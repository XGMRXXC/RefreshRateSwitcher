# RefreshRateSwitcher

小米平板 / 红米 K Pad（`25079RPDCC` / `turner`）与小米 17 Pro 的**刷新率切换器**，
带 KernelSU 模块（常驻通知 / 点击切换并锁定刷新率），支持按应用自动切换。

## 功能

- 一键切换 / 锁定刷新率（24 / 30 / 60 / 90 / 120 Hz 等，按机型实际模式列出）
- 常驻通知：点击切换、通知内快捷挡位
- 悬浮窗面板：长按拖动位置、⟲ 恢复默认位置、进入应用
  - **位置记忆按竖屏 / 横屏分别保存**，两种 UI 共享同一份记忆
- 按应用自动切换：前台应用规则，触发时**不改变锁定状态**
- LTPO 屏幕：自动解除无效锁定，界面显示「由 LTPO 控制 / 最高到 N Hz」
- 应用列表：下拉刷新（MIUIX 原生）、规则应用置顶排序、实时图标缓存
- 双主题：MIUIX 与 Material 3 Expressive，可切换；横屏精简顶栏
- KSU 模块：开机自动拉起、崩溃守护

## 构建

需要 JDK 21、Android SDK（compileSdk 36 / minSdk 29）、Gradle 8.14.3、AGP 8.13.2。

```bash
gradle :app:assembleRelease
```

## 产物

- `release/RefreshRateSwitcher-4.2.1.1.apk` —— 主程序
- `release/RefreshRateSwitcher-4.2.1.1-KSU.zip` —— KernelSU 模块（内含同一 APK）

## 模块

`ksu_module/` 为 KernelSU 模块源文件；把 `module.prop`、`service.sh`、`action.sh`、
`uninstall.sh` 与 APK 一起打包为 zip 即为可刷入模块。
